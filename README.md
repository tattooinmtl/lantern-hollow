# Lantern Hollow

First-person low-poly maze. Find the glowing exit.

WASD to move, mouse to look, Space to jump. On a phone, use the stick, drag to look, and the on-screen buttons. Dead-end chests hold keys, potions, and ammo. Drag items out of the pack to drop them. The torch, traps, and an 8-round handgun are all in the hollow with you.

```bash
npm install
npm run dev
```
